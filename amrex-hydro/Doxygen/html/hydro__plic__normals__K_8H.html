AMREX_GPU_HOST_DEVICE AMREX_FORCE_INLINE bool PLIC::height_normal (const int i, const int j, const int k, const int d, amrex::Array4< amrex::Real const > const &F, amrex::Real m[3])
 Height-function normal with height direction d: the liquid heights of the 7-cell columns through (i,j,k) and its neighbors in the tangential directions, differenced centrally. Exact for a planar interface whose slope relative to d is at most 1, which holds for the dominant normal direction. Returns false (m untouched) unless each column, the center one included, crosses the interface once: from pure liquid to pure gas in the orientation of the center column, with F monotone in between. A thin gas gap with a liquid sliver inside a column is not a height, and the caller falls back to another normal.

Detailed Description

Interface normals of the PLIC reconstruction, and the plane fit that takes one of them as a template parameter. The comment above the schemes below says how to add one.

The Mixed Youngs-Centered normal is that of Aulisa et al. (JCP 225, 2007). Derived from Kynema-SGF (formerly AMR-Wind), src/equation_systems/vof, BSD 3-Clause License, Copyright (c) 2020, Alliance for Energy Innovation and Regents of the University of California.
