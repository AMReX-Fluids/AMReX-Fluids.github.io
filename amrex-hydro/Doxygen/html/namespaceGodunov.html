Compute the edge state of q.

Note
Ghost-cell requirements: q needs 3 filled ghost cells, the MAC velocities need 1, and divu needs 1.
divu must be a valid Array4 in 3D for every component: it is read through the corner coupling when iconserv[n] is set, and through the final edge-state update when it is not. In 2D it is only read when iconserv[n] is not set.
