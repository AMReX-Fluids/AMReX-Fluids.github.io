◆ setAlpha()

void Hydro::NodalProjector::setAlpha ( const amrex::Vector< const amrex::MultiFab * > &  a_alpha)
inline

Set alpha for the custom mode. alpha is stored as raw pointers, so it must outlive the projector, and it persists until it is reset. Pass an empty vector to go back to the default alpha = 1.
