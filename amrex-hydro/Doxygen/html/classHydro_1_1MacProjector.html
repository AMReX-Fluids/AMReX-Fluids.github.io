◆ setDivU()

void Hydro::MacProjector::setDivU ( const amrex::Vector< amrex::MultiFab const * > &  a_divu)

Set div(U)

The source term S is copied into internal storage and persists until it is overwritten by another call. Passing an empty vector, or a vector whose entry for a level is a nullptr, resets S to zero on the levels not supplied. This matters when one MacProjector object is reused across time steps.
