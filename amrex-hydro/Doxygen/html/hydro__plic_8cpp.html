void PLIC::SharpFaceDensity (FacePtrs const &rho_face, amrex::Vector< amrex::MultiFab const * > const &F, amrex::Geometry const &geom, PhaseDensity const &rho_l, PhaseDensity const &rho_g, std::string const &reconstruction)
 Face density rho_g + (rho_l - rho_g) * <face_segment_fraction>, with the average over the given volume fractions, and each phase density a value or a field (PhaseDensity). For a planar interface normal to gravity it makes rho_face * g a discrete gradient, which is the hydrostatic balance of a balanced-force projection (Francois et al., JCP 213, 2006). Each face gets one value. On several AMR levels, call it on each: the MAC projection averages the coefficients of a fine level down onto the coarse faces it covers.
